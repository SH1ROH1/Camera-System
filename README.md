# Camera System — Universal

A modular and flexible camera system for Unreal Engine.

## Features
- Flexible camera positioning and rotation.
- Smooth and instant camera transitions.
- Target tracking and following.
- Multiple camera control modes.
- Configurable camera behavior.
- Extensible architecture for different gameplay styles.

## Compatibility
- Unreal Engine 5

## Installation
1. Download or clone the repository.
2. Place the plugin in your project's `Plugins` directory.
3. Enable the plugin in Unreal Engine.
4. Restart the editor if required.
